# 官网前端

这是独立的公开官网前端首版，目标是承接品牌展示、内容资讯和在线申请入口，由现有后台系统提供品牌配置与后续 CMS 管理能力。

## 当前边界

- 不复用 `frontend/` 的后台管理布局，避免公开官网带上后台权限、菜单和控制台体验。
- 读取现有公开接口 `/api/v1/public/branding-settings`，接口不可用时使用本地默认品牌兜底。
- 目前页面内容是静态首版，用来固定视觉方向和官网信息架构。
- 后续接入 CMS 后，首页区块、导航、资讯列表、表单定义都应从公开 API 获取。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 4174 --directory website
```

然后访问：

```text
http://localhost:4174
```

如果要联调后端公开接口，建议后续由网关或开发代理把 `/api` 转发到后端服务。
