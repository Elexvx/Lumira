## 已修复问题

### 1. 后台新增学生失败

依次修复了角色查询引用不存在字段、关联表 upsert 列名歧义、事务内异步读取看不到新用户的问题。后台已成功创建并启用测试学生，角色绑定正确。

### 2. 普通学生无法创建报名项目（P1）

根因不是 Common User 缺少 `aiadc:registration:create`。全局敏感词过滤器在扫描所有写请求时错误要求 `plugin:sensitive-words:view` 后台管理权限，因此学生写请求在进入项目控制器前即返回 `A0403`。

修复后：

- 敏感词词库查看与管理权限仍只对管理员开放；
- 已登录可信用户的表单提交仍执行敏感词扫描，但不要求后台词库查看权限；
- 输入框实时敏感词检查采用同一规则；
- 学生创建项目线上回归通过。

### 3. 不同账号恢复同一报名草稿（P1 数据隔离）

根因是报名草稿使用全局固定 localStorage key。现已升级为按登录用户 ID 分区的 v2 key，旧公共 key 不再读取。线上刷新验证通过。
