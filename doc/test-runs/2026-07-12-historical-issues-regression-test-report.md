# Lumira 历史问题复核与回归测试报告

## 1. 测试结论

截至 2026-07-12，历史《赛事报名与角色权限测试报告》中记录的 3 个功能缺陷均已修复，相关后端回归测试 148/148 通过，前端报名草稿隔离测试通过，未发现这些缺陷发生功能回退。

当前不能给出“所有问题均已关闭”的结论，仍有以下未关闭事项：

1. 前端登出单元测试稳定失败 2 条，原因为 `sessionLifecycle.ts` 在 Node 测试环境直接读取 `window.location`；该问题阻塞前端全量自动化测试达到 100% 通过。
2. 赛事报名成员表格的自适应修复已有代码和自动化证据，但历史 QA 缺少登录后的浏览器截图复验，视觉验收仍未闭环。
3. 真实支付、配置初赛材料后的文件上传限制仍未执行，属于测试覆盖缺口，不属于已确认功能缺陷。

综合结论：**历史 P1 功能缺陷已关闭；当前无已确认的 P0/P1 功能缺陷，但存在 1 个 P2 自动化测试问题、1 个 P2 视觉验收缺口，以及 2 项业务链路未覆盖。建议在补齐上述验证后再签署“全部问题关闭”。**

## 5. 未关闭问题

### OPEN-001：前端登出单元测试在无浏览器环境失败

- 等级：P2
- 状态：未修复
- 位置：`lumira-ui/src/auth/sessionLifecycle.ts:31`
- 影响用例：
  - `clears local session and redirects without waiting for server logout`
  - `falls back logout request to legacy endpoint when v2 is unavailable`
- 错误：`ReferenceError: window is not defined`
- 原因：`buildLogoutRedirectTarget` 的默认参数直接求值 `window.location`，而当前 Vitest 环境为 Node。
- 影响：浏览器运行时不一定触发该错误，但 CI/本地前端全量单测无法 100% 通过，登出逻辑缺少可靠回归保障。
- 建议：让函数显式接收 location，或对 `window` 不存在的环境提供安全默认值，并保留当前两个测试覆盖。

### OPEN-002：成员表格自适应缺少浏览器视觉复验

- 等级：P2（验收缺口）
- 状态：阻塞于生产登录态
- 影响：代码与自动化层面已验证，但无法确认最终生产页面在目标桌面宽度下完全无横向滚动、操作列始终可见。
- 建议：登录生产环境，进入报名向导第 2 步，使用两个成员字段和一名已保存成员复现原场景；补充全页及表格区域截图，并验证新增/编辑状态。

## 6. 非稳定失败与测试稳定性风险

默认并行执行前端全量测试时，`paymentAuthenticatedRequest.test.ts` 出现 1 条 5 秒超时及 1 条 Mock 连带失败。该文件单独执行 2/2 通过，全量测试限制为单 worker 后也通过，因此本报告不将其认定为稳定功能缺陷。

建议后续检查动态导入耗时、测试超时配置和 Mock 清理，降低资源竞争导致的偶发失败，避免 CI 误报。
